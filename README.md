# HTML Projects — Output Screenshots

This repository contains three HTML/CSS/JavaScript interface projects. The screenshots are included to show the initial browser output of each supplied HTML file.

## Projects

### 1. AccessHub — Login & Register
A responsive login, registration, and password-recovery interface. It includes form validation and demo-only browser storage for account/session examples.

**Main file:** `ABL 1.html`  
**Screenshot:** `screenshots/accesshub.png`

### 2. Orbit — Project Workspace
A project-workspace dashboard interface with navigation, project cards, summary information, and a task-board layout.

**Main file:** `ABL 2.html`  
**Screenshot:** `screenshots/orbit.png`

### 3. BusGo — Find Your Seat
A bus seat-selection and journey interface with a bus illustration, route information, and seat-booking panel.

**Main file:** `ABL 3.html`  
**Screenshot:** `screenshots/busgo.png`

## Technologies
- HTML for page structure
- CSS for layout, colors, and responsive styling
- JavaScript for interactive behavior in the supplied pages

## How to View
1. Download or clone the project files.
2. Keep each HTML file with any related assets it requires.
3. Open the relevant HTML file in a modern web browser.

## Output Screenshots
The screenshots show the pages in a desktop browser viewport. Some controls are demo interfaces; for example, AccessHub explicitly indicates that real authentication requires a secure backend.

## Note
These screenshots were generated from the supplied HTML files. External fonts or resources may look different if they are unavailable in the browser.
